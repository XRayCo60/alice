# Alice-telbot

ربات تلگرامی بازی کشوری با موتور نبرد ترکیبی نسخه ۲.

## اجرای خودآزمایی

```bash
dotnet run -- selftest 20
```

## ترکیب مدل‌های نظامی

در حمله مستقیم و صف‌آرایی، تانک‌ها، جنگنده‌ها و بمب‌افکن‌ها بر اساس مدل انتخاب و ثبت می‌شوند. موتور نبرد مشخصات هر مدل تانک را در سطح گروه رزمی و مشخصات هواپیماها را متناسب با تعداد واقعی مدل‌های اعزامی محاسبه می‌کند. تلفات مشارکت‌کنندگان صف‌آرایی نیز جداگانه نگهداری و تسویه می‌شود.
