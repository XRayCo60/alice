# Alice-telbot

ربات تلگرامی بازی کشوری — موتور نبرد در `WarEngine.cs`.

## خودآزمایی موتور نبرد

بدون نیاز به تلگرام و دیتابیس، توزیع نتایج، صحت‌سنجی تلفات و تعیین‌پذیری موتور را چک کنید:

```bash
dotnet run -- selftest        # ۲۰ شبیه‌سازی در هر سناریو
dotnet run -- selftest 50     # ۵۰ شبیه‌سازی در هر سناریو
```

## تراز بازی

پارامترهای تعادل در بالای کلاس `WarEngine` (ثابت‌های `*_POWER_FRACTION`، `HOMELAND_COMBAT_BONUS`،
`LOOT_*_FRACTION` و...) تعریف شده‌اند.
